# DealFlow360

## Customer activation email

Customer activation tokens are generated by the backend, stored only as hashes, and expire after 24 hours. Configure SMTP delivery with these backend environment variables:

```env
SMTP_HOST=
SMTP_PORT=587
SMTP_USER=
SMTP_PASSWORD=
SMTP_FROM=
```

When SMTP is not configured or delivery fails, the Admin still receives the raw token from the Admin-only customer activation response and the UI clearly reports that email delivery failed.
